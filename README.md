# 🚀 Base de Conhecimento - Monitoria (Hack Ops)

Este repositório centraliza a base de conhecimento e os comandos de suporte rápido para facilitar o dia a dia dos estagiários.

## 🛠️ Como usar o Assistente CLI
1. Baixe o arquivo `baseconhecimento.bat`.
2. Execute o arquivo.
3. Escolha a opção desejada no menu, copie o comando gerado e cole no seu CMD.
4. Lembre-se de alterar o "X" pela sub-rede da sala correta.

## 📚 Protocolos Diários (Helpdesk e Monitoria)
* **Aplicação de Provas:** O Helpdesk cadastra na intranet. O monitor deve usar a Opção 2 do script para espelhar a prova da máquina do professor para o disco `D$` de todas as máquinas dos alunos.
* **Limpeza Pós-Prova:** Para evitar resquícios de arquivos, use a Opção 3 do script para formatar os diretórios `D$` das 50 máquinas da sala de uma só vez.
* **Troubleshooting de Áudio:** Dificuldades com som nas aulas? Use a Opção 4 para forçar o start do `Audiosrv` remotamente em todo o laboratório.
